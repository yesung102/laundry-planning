# 저장: "정리하자"에 답하는 법

기획자가 "정리하자", "저장해줘" 또는 같은 뜻으로 말하면 이 문서를 따른다.

## 순서

1. 마지막 저장 이후 대화에서 정한 것, 바뀐 것, 미룬 것을 목록으로 만들어 기획자에게 보여 주고 확인받는다.
2. 원문 기획서(`01`~`07` 폴더의 md)를 고친다.
3. 장부(`index.html`)를 고친다. 아래 '장부의 구조'를 따른다.
4. 저장 이력 맨 위에 기록을 추가한다. 무엇이 바뀌었고 왜 바뀌었는지 적는다.
5. 첫 화면의 마지막 정리 날짜를 고친다.
6. 배포가 연결되어 있으면 저장소에 동기화하고, 공개 주소에서 바뀐 것이 보이는지 확인한다. 연결되어 있지 않거나 올리지 못했으면 로컬에만 저장됐다고 분명히 말한다.

## 원칙

- 합의한 문장만 해당 주제 맨 위에 쓴다.
- 아이디어, 시험값, 개발자 협의, 보류, 폐기, 대체는 주제 바로 아래 `<details>`에 두고 상태와 근거를 적는다.
- 두 안이 열려 있으면 둘 다 남긴다.
- 이전 저장 이력은 지우지 않는다. 같은 내용은 두 번 적지 않는다.
- 저장소에는 기획 원문과 장부를 포함한 프로젝트 전체를 올린다.

## 장부의 구조

장부는 저장소 맨 위 `index.html` 한 파일이다. 화면 하나가 `<section class="view" id="…" data-view>` 하나다.

| 화면 | id | 언제 고치나 |
|---|---|---|
| 첫 화면(기획 지도) | `home` | 지금 할 곳, 단계 상태, 일감이 바뀔 때 |
| 단계 화면 | `stage-1` ~ `stage-8` | 그 단계에서 정한 것과 남은 것이 바뀔 때 |
| 게임 그림 | `game` | 한 벌의 흐름이나 시스템 사이의 연결이 바뀔 때 |
| 정한 것 | `ledger` | 규칙을 정하거나 바꿀 때 |
| 남은 질문 | `questions` | 질문이 생기거나 풀릴 때 |
| 용어 | `words` | 새 용어가 나올 때 |
| 저장 이력 | `history` | 저장할 때마다 |

### 상태 동그라미

| 표시 | 뜻 |
|---|---|
| `<i class="st done">` | 많이 됨 |
| `<i class="st part">` | 일부만 |
| `<i class="st empty">` | 비어 있음 |
| `<i class="st later">` | 나중 |

단계 상태는 두 곳에 있다. 첫 화면 지도의 `<li>`와 단계 화면 맨 위의 `<p class="stage-no">`다. 동그라미 옆의 글자도 함께 고친다.

### 지금 할 곳을 옮길 때

1. 지도에서 `aria-current="step"`과 `<em class="flag">지금 여기</em>`를 새 단계의 `<a>`로 옮긴다.
2. 첫 화면 `<div class="now">` 안의 제목, 설명, 단추 주소, 말 걸기 예시를 새 단계에 맞게 고친다.
3. 단계 화면 맨 위의 `<span class="tag solid">지금 여기</span>`를 새 단계로 옮긴다.

### 규칙을 정했을 때 (정한 것 화면)

- 주제 하나가 `<article class="record" id="…">` 하나다.
- 합의한 문장은 주제 맨 위 `<p>`에 쓴다.
- 나머지는 그 아래 `<details>` 안 `<dl>`에 `<dt>상태</dt><dd>내용과 근거</dd>`로 적는다. 상태 예: 시험값, 보류, 폐기, 대체, 협의, 제안.
- 주제 제목 아래 꼬리표는 `<span class="tag solid">정함</span>` 또는 `<span class="tag">이야기 중</span>`이다. 그 옆에 속한 단계를 적는다.
- '이야기 중'이던 주제가 정해지면 `<div id="drafts">`에서 `<div id="decisions">`로 옮긴다. 꼬리표와 주제 목록(`<ul class="index">`)의 동그라미도 고친다.
- 새 주제를 만들면 주제 목록에도 한 줄을 추가한다.

### 단계 화면

- '이미 정한 것'은 `<ul class="ticks yes">`, '아직 남은 것'은 `<ul class="ticks">`다. 정해진 항목은 아래 목록에서 위 목록으로 옮긴다.
- 그림 안의 빈칸(`class="box hole"`)이 채워지면 `hole`을 지우고 내용을 적는다.
- 02 단계의 질문 표는 답이 생길 때마다 '지금 적혀 있는 것'과 상태 동그라미를 고친다.

### 남은 질문

- 질문 하나가 `<li>` 하나다. 묶음은 다섯 개다. 지금 정할 것, 기획자가 고를 것, 시제품을 해 봐야 정해지는 것, 개발자와 함께 정할 것, 숫자를 넣을 때 정할 것.
- 정해지면 그 `<li>`를 지우고 내용을 정한 것 화면에 적는다.
- 새로 미룬 것은 맞는 묶음에 추가한다.

### 용어

`<dl class="words">` 안에 `<div id="w-이름"><dt>용어</dt><dd>한 줄 풀이</dd></div>`를 추가한다. 본문에서 그 용어를 `<a class="term" href="#w-이름">용어</a>`로 감싸면 누를 때 풀이가 뜬다.

### 저장 이력

`<section id="history">` 안 맨 위에 `<article class="log">`를 추가한다. 날짜, 무엇이 바뀌었는지 한 줄 제목, 왜 바뀌었는지를 적는다.

### 고치지 않는 것

- `<style>`과 `<script>`.
- 그림과 목록의 class 이름. 글자만 고친다.
- `laundry-planning/index.html`과 `세탁소_기획_장부.html`. 예전 주소를 맨 위 `index.html`로 넘겨 주는 연결 파일이다.

## 저장한 뒤 기획자에게 말할 것

- 무엇을 장부의 어디에 넣었는지 두세 줄.
- 동그라미가 바뀐 단계가 있으면 그 단계.
- 다음에 할 곳.
- 공개 주소에 올라갔는지, 로컬에만 있는지.
